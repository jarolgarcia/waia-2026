# Frontend futuro / frontera de API

Esta carpeta se conserva como espacio de transición para una futura separación formal del frontend y la capa REST. La aplicación demo activa hoy está en el `src/` raíz para preservar el proyecto existente.

Cuando se conecte el backend, la capa de servicios debe cambiar de datos locales a REST sin modificar las páginas ni los componentes.
