# WAIA — fuentes de referencia turística

## INTUR

Portal actual de consulta de oferta turística registrada:

- https://tramites.intur.gob.ni/siit/public/site/empresasTuristicas.html
- https://tramites.intur.gob.ni/siit/public/site/mapaInturNicaragua.html

Categorías usadas como referencia de estructura: hospedaje, restaurantes, bares, cafeterías, agencias de viajes, tour operadoras, centros recreativos, transporte turístico, rent a car, guías turísticos y turismo de naturaleza/rural.

## Territorio nacional

El catálogo territorial usado por WAIA toma como referencia el Anuario Estadístico 2023 de INIDE / INETER para la división de 15 departamentos, 2 regiones autónomas y 153 municipios.

## Imágenes

Las imágenes verificadas de referencia se almacenan con `sourceUrl`, `sourceName`, `photographer` y `license` cuando esa metadata fue comprobada.
